# FreeTools Hub — MVP v1

A responsive, static-first website containing six free tools:
- E-commerce Profit Calculator
- Product Pricing Calculator
- Marketplace Fee Calculator (editable illustrative rates)
- Freelance Hourly Rate Calculator
- Amazon FBA Profit Estimator (user-entered current fees)
- Free Invoice Generator (print / save as PDF)

## Run locally

From this folder, start any static file server. For example, with Node installed:

```bash
npx serve . -l 8080
```

Then open `http://127.0.0.1:8080` on the same device. You can also open `index.html` directly in a browser.

## Architecture

- Static HTML/CSS/JavaScript; no backend or database in v1.
- Calculations and invoice preview run locally in the browser.
- No account, subscription, or daily quota.
- Ready for static hosting. Add analytics, consent management and advertising only after reviewing privacy requirements and publishing a complete privacy/cookie policy.

## Before public launch

1. Replace the placeholder contact email.
2. Review and expand the privacy policy, terms and contact/about information.
3. Verify all fee defaults and label them clearly; marketplace fees change by country, category and date.
4. Test on mobile and desktop.
5. Connect a real domain and submit the site for indexing.
6. Apply to an ad network only after the site has enough original, useful content and all policy pages are complete.

This is an MVP starter, not a guarantee of advertising approval or revenue.
